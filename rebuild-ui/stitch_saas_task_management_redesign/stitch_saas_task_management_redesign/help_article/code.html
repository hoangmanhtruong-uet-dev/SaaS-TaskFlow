Configuring Webhooks & Real-Time API Triggers in TaskFlow

Learn how to securely stream issue updates, assignee changes, and pipeline events directly to your internal services using TaskFlow's high-velocity webhook engine.

1. Overview of TaskFlow Webhooks

Webhooks allow your external applications to be notified automatically when specific events occur within your TaskFlow workspace. Instead of continuously polling our REST API, your servers can listen for real-time payloads signed with HMAC-SHA256 for absolute security.

lightbulb Pro Tip: Payload Delivery Guarantee

TaskFlow automatically retries failed webhook deliveries up to 5 times with exponential backoff over a 24-hour window. Ensure your endpoint responds with a 2xx status code promptly.

2. Security & Request Signatures

Every incoming request from TaskFlow includes a custom HTTP header: X-TaskFlow-Signature. You should verify this signature before processing payloads to prevent spoofing.

Node.js Verification Example 
const crypto = require('crypto');

function verifyWebhook(reqBody, signatureHeader, secret) {
  const hmac = crypto.createHmac('sha256', secret);
  const digest = hmac.update(JSON.stringify(reqBody)).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(signatureHeader), Buffer.from(digest));
}

3. Inspecting Payload Structure

Payloads are delivered via standard POST requests with a application/json content type. Below is an example event payload for a task state change: 

{
  "event": "task.status_changed",
  "timestamp": 1728912044,
  "workspace_id": "ws_9981240a",
  "data": {
    "task_id": "TF-8492",
    "title": "Optimize database indexing queries",
    "previous_status": "in_progress",
    "current_status": "completed",
    "assignee": {
      "id": "usr_4401",
      "name": "Alex Mercer"
    }
  }
}

4. Common Troubleshooting Steps

If your endpoints are not receiving events, check the following common pitfalls:

  • Firewall rules blocking outbound IP ranges from TaskFlow servers.
  • Endpoint timeouts exceeding the 5-second hard limit.
  • Using outdated signing secrets after a manual key rotation cycle.
